# KAIROS

**Continuidad de negocio: BIA, BCP y DRP con ruta crítica de recuperación.** ISO 22301 · ISO/IEC 27001 · ENS op.cont.

KAIROS calcula si cada función de negocio vuelve dentro de su RTO. Para ello recorre la cadena de dependencias: activos TIC, otras funciones y proveedores. También compara el RPO con la frecuencia real de las copias y revisa el plan con 28 reglas de preauditoría.

- **App:** `dist/index.html`. Es un único fichero HTML, sin servidor ni peticiones de red.
- **Código:** `app/src`. Para regenerarlo, ejecuta `node app/build.js`.
- **Pruebas del motor:** `node --test tests/engine.test.js`.
